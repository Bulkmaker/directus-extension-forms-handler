## [1.1.0] — 2026-09-06
### Fixed
- **HTML-инъекция в Telegram-уведомления.** `attachments[].url` уходил в `sendMessage`
  (`parse_mode: HTML`) без экранирования — анонимный `POST /forms/submit` мог вставить
  свою кликабельную ссылку в рабочую группу заявок (фишинг по сотрудникам), а кривой
  тег ронял парсер Telegram → 400 → уведомление о лиде не приходило вовсе. Теперь
  `escapeHtml(item.url)`.
- **Выход из `href="…"` через кавычку.** `escapeHtml` не трогает `"`, а `source_url` и
  `attachments[].url` приходят из тела запроса. Добавлен `escapeHtmlAttr` (кавычки →
  `&quot;`/`&#39;`), применён во всех атрибутных позициях Telegram- и email-шаблонов.
- **Схема вложений.** `attachments[].url` теперь `.max(500).url()` + только `http(s)`.
  Невалидная ссылка НЕ отклоняет заявку (лид дороже ссылки) — вложение уезжает без URL.
- **Утечка параметров антиспама клиенту.** Ответ 400 больше не содержит `details`
  антиспама («5 requests per 60s», «1s < 3s minimum») — по ним спамер калибровал обход.
  Причина пишется в серверный лог. Ошибки валидации полей формы клиенту возвращаются
  как раньше (их показывает пользователю форма).

### Changed
- **Rate-limit (in-memory) чистит истёкшие записи.** Ключи Map никогда не удалялись:
  рассылка с ротацией IP наращивала стор без потолка → OOM Directus (Redis в стеке не
  используется, `CACHE_STORE=memory`). Добавлены периодический sweep (раз в 60с, таймер
  ленивый и `unref()`-нутый — не держит процесс и не дублируется при повторной
  инициализации модуля) и жёсткий потолок в 20 000 ключей.
- **Time-check: допуск clock-skew ±5 минут** (коммит 7c70a4d от 05.09): у клиентов со
  спешащими часами форма не отправлялась. В `dist` до 1.1.0 не попадал.

### Build
- CI-сборка `dist` падала с 2026-09-05 (`npm install` → ERESOLVE vite 8 vs
  `@vitejs/plugin-vue` → `Cannot read properties of null (reading 'edgesOut')`).
  Закоммичен `package-lock.json`, workflows переведены на `npm ci` и Node 24 (npm 11).
  `dist` 1.1.0 собран локально из актуального `src` (102 теста зелёные), тег v1.1.0
  стоит на коммите с этим `dist`.

**Безопасно обновлять:** ✅ да — контракт `POST /forms/submit` для валидных заявок не
изменился. Единственное отличие ответа: при отказе антиспама пропало поле `details`
(фронт `useUniversalFormSubmit` читает его как `response.details || []`).
